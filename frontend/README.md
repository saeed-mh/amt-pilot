# AmtPilot frontend

Vue 3 single-page interface for authentication, process discovery, application tracking, document management, and grounded AI review.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```

The development server expects the Spring Boot API at `http://localhost:8080`. The Vite proxy configuration forwards `/api` requests to that backend.

For full-project setup and architecture, see the [root README](../README.md).
